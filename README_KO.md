# CustomSena 사용 안내

`customsena`는 Sena 60S의 음성 프롬프트를 원하는 음원으로 교체하고, 커스텀 음성 펌웨어를 검증한 뒤 USB로 설치하는 macOS용 프로그램입니다.

이 문서는 배포된 `customsena` 실행 파일을 사용하는 분을 위한 독립 안내서입니다.

## 1. 지원 기능

- Sena 60S 공식 베이스 펌웨어 선택 및 다운로드
- 펌웨어의 음성 프롬프트 목록 확인
- MP3, WAV, M4A 등 음원으로 프롬프트 교체
- 음원 자동 변환 및 펌웨어 용량에 맞춘 인코딩
- 커스텀 펌웨어 빌드·무결성 검증
- Sena 60S 장치 확인 및 정보 표시
- 장치 전체 16MiB 백업
- 실제 설치 전 사전검사
- voice FOTA 설치

지원 대상은 Sena 60S의 Airoha 음성 FOTA입니다. QCC 외부 MCU 업데이트나 다른 Sena 제품은 지원하지 않습니다.

## 2. 실행 환경

- macOS
- Sena 60S
- 데이터 통신이 가능한 USB 케이블
- 공식 펌웨어를 처음 다운로드할 때 인터넷 연결

배포된 `customsena` 실행 파일을 실행하면 TUI가 시작됩니다.

## 3. 사용 순서

배포된 `customsena` 파일을 실행한 뒤, TUI에서 다음 순서로 진행합니다.

```text
1. 베이스 펌웨어 선택   /firmware <language>
2. 교체 음원 선택        /prompt <id> <audio-path>
3. 펌웨어 빌드·검증      /build
4. 장치 백업             /backup
5. 설치 준비             /install
6. 설치 확인             /confirm
```

각 단계가 완료된 뒤 다음 단계로 넘어가세요. 특히 `/install`은 장치·백업·펌웨어 호환성을 검사하는 단계이며, 모든 검사가 통과한 뒤 `/confirm`으로 실제 설치를 시작합니다.

## 4. 베이스 펌웨어와 프롬프트 선택

TUI 입력창에서 다음과 같이 입력합니다.

```text
/firmware Korean
```

지원 언어:

`English`, `French`, `Spanish`, `Italian`, `German`, `Korean`, `Japanese`, `Dutch`, `Russian`, `Chinese`, `Finnish`, `Polish`

선택한 펌웨어의 실제 locale과 프롬프트 목록이 표시됩니다. 목록에서 검색하거나 카테고리로 좁혀 원하는 음성 ID를 찾습니다.

언어별 펌웨어는 프롬프트 구성이 다를 수 있으므로, 다른 펌웨어에서 확인한 ID를 그대로 사용하지 마세요.

## 5. 음성 교체와 펌웨어 빌드

프롬프트를 선택한 뒤 음원 파일을 지정합니다.

```text
/prompt <id> <audio-path>
```

Finder에서 음원 파일을 선택한 프롬프트 위로 끌어다 놓을 수도 있습니다. 여러 프롬프트를 교체하려면 각각 지정합니다. 잘못 선택한 음원은 `/restore <id>`로 원본으로 되돌릴 수 있습니다.

언어별 프롬프트 의미는 다음과 같습니다.

| 프롬프트 ID | English | 한국어 |
| --- | --- | --- |
| `7` | `hello` | `안녕하세요` |
| `5` | `goodbye` | `감사합니다` |

같은 프롬프트 ID라도 선택한 베이스 펌웨어 언어에 따라 실제 음성이 달라집니다. 영어 펌웨어의 7번은 `hello`, 한국어 펌웨어의 7번은 `안녕하세요`입니다. 영어 펌웨어의 5번은 `goodbye`, 한국어 펌웨어의 5번은 `감사합니다`입니다.

준비가 끝나면 다음 순서로 빌드합니다.

```text
/build
```

빌드 과정에서 음원은 16 kHz mono MP3로 변환됩니다. 음성 영역이 부족하면 40, 32, 24, 16, 8 kbps 순서로 자동 재인코딩합니다. 8 kbps에서도 용량이 부족하면 교체하는 음원의 개수나 길이를 줄여야 합니다.

빌드가 성공하면 커스텀 `.img` 파일과 검증 보고서 `.img.customsena.json`이 실행 파일과 같은 폴더에 생성됩니다. 두 파일을 함께 보관하세요.

## 6. 장치 확인과 백업

Sena 60S를 USB로 연결하면 TUI에서 장치 상태를 확인할 수 있습니다. 장치가 검색되지 않으면 `/detect`로 다시 검색합니다.

설치 전에 반드시 백업을 실행합니다.

```text
/backup
```

백업은 전체 16MiB 플래시를 읽으며 오래 걸릴 수 있습니다. 백업 중에는 USB를 분리하지 마세요. 백업 파일과 SHA-256 보고서는 실행 파일과 같은 폴더에 생성됩니다.

현재 프로그램은 백업 생성·검증은 지원하지만, 백업 파일을 장치에 복원하는 기능은 제공하지 않습니다. 백업이 있다고 자동 복구가 보장되는 것은 아닙니다.

## 7. 설치

앞의 단계들을 완료한 뒤 TUI 입력창에 다음을 입력합니다.

```text
/install
```

프로그램은 다음 항목을 자동으로 확인합니다.

- 커스텀 이미지의 외부 MD5 및 voice FOTA SHA
- voice FOTA 제품명 `AB1585_Headset`
- 장치 제품명 `Sena Headset HID`
- AB158x SDK 버전
- FOTA 파티션 offset과 크기
- 연결된 장치와 백업의 일치 여부
- voice FOTA 용량

모든 검사가 통과하면 확인 단계가 표시됩니다. 실제 설치를 진행하려면 다음을 입력합니다.

```text
/confirm
```

취소하려면 다음을 입력합니다.

```text
/cancel
```

## 8. 사용법

### 주요 TUI 명령

| 명령 | 기능 |
| --- | --- |
| `/status` | 현재 장치·펌웨어·백업 상태 표시 |
| `/detect` | 장치 다시 검색 |
| `/firmware <language>` | 공식 베이스 펌웨어 선택 또는 다운로드 |
| `/prompt <id> <audio-path>` | 교체 음원 지정 |
| `/restore <id>` | 해당 프롬프트를 원본으로 복원 |
| `/build` | 커스텀 펌웨어 빌드·검증 |
| `/backup` | 장치 전체 백업 |
| `/install` | 설치 검사 및 확인 단계 시작 |
| `/confirm` | 확인된 설치 실행 |
| `/cancel` | 설치 확인 취소 |
| `/set base\|output\|backup <path>` | 경로 직접 지정 |
| `/help` | 도움말 표시 |

### 키보드와 마우스

- `1`~`4`: 화면 이동
- `↑`/`↓`: 선택 이동
- `Enter`: 선택 또는 실행
- `/`: 명령 및 프롬프트 검색
- `L`: 한글/영문 전환
- `?`: 도움말
- `Q`: 종료

메뉴와 버튼은 마우스로 클릭할 수 있습니다. 실행 중인 작업이 끝나기 전에는 TUI를 종료하지 마세요.

## 9. 주의사항

### 실제 장치에 기록합니다

설치가 시작되면 Sena 60S의 FOTA staging 영역이 수정됩니다. 잘못된 장치·이미지·백업을 사용하거나 USB 연결이 끊기면 문제가 발생할 수 있습니다.

### 반드시 대상 장치에서 백업하세요

다른 장치에서 만든 백업을 사용하지 마세요. 프로그램은 연결된 장치와 백업의 일부를 비교하지만, 사용자가 모델과 파일을 먼저 확인해야 합니다.

### USB 연결을 유지하세요

백업과 설치 중에는 USB 케이블을 분리하거나 Mac이 잠자기 상태가 되게 하지 마세요. 불안정한 USB 허브나 케이블은 피하세요.

### 생성된 이미지 파일을 직접 수정하지 마세요

`.img` 파일을 헥스 에디터 등으로 직접 수정하면 MD5, SHA, 압축·암호화 구조가 깨질 수 있습니다. 변경이 필요하면 TUI에서 다시 빌드하세요.

### 음원 파일을 확인하세요

macOS에서 재생 가능한 음원을 사용하세요. 프롬프트 ID는 중복 지정할 수 없습니다. 음성 공간이 부족하면 음원의 길이나 교체 개수를 줄이세요.

### 지원 범위를 벗어난 장치에는 사용하지 마세요

검사 오류를 무시하거나 안전 검사를 우회하지 마세요.

## 10. 문제 발생 시

1. Sena 60S가 USB로 연결되어 있는지 확인합니다.
2. TUI에서 `/detect`를 실행합니다.
3. TUI에 표시되는 제품명과 SDK 정보를 확인합니다.
4. 선택한 베이스 펌웨어의 언어와 프롬프트 ID를 다시 확인합니다.
5. 커스텀 이미지와 `.img.customsena.json`을 함께 보관했는지 확인합니다.
6. 백업 파일이 16MiB인지 확인합니다.
7. 오류가 발생하면 USB를 반복해서 분리하지 말고 오류 메시지와 장치 상태를 먼저 기록합니다.

오류를 공유할 때는 serial 번호 등 개인 식별 정보가 포함된 값은 가리고, 사용한 펌웨어 파일명과 오류 메시지를 함께 기록하세요.
